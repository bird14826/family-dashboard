# 🎮 우리집 가족 대시보드

이든 · 이솔 · 이온이의 **포켓몬 마을(개인 보관함)**, 오늘 일정과 준비물, 가족 캘린더, 위시리스트를 태블릿 한 화면에서 보는 가족용 대시보드입니다.

**바로 열기 → https://bird14826.github.io/family-dashboard/**

## 화면 구성 (상단 탭)

태블릿을 가로로 두고 쓰도록 만들었습니다. 위쪽 한 줄 탭으로 화면을 바꿉니다.

| 탭 | 내용 |
| --- | --- |
| 🎮 포켓몬 | 지금 키우는 포켓몬(알·진화 단계·스티커) + 아이의 포켓몬 마을 + 최근 스티커 |
| 🏠 대시보드 | 오늘 일정·준비물, D-Day, 가족 캘린더, 가족 우체통, 송도 날씨 |
| 🔥 이든 · ⚡ 이솔 · 💧 이온 | 그 아이의 포켓몬 마을로 바로 이동 |
| ✅ 퀘스트 | 아이별 퀘스트·XP·레벨 (퀘스트를 끝내면 스티커 1장) |
| 🗓️ 일정 | 오늘 일정·준비물 + D-Day + 가족 캘린더를 크게 |
| 🎁 위시·우체통 | 이거 사주세요!(위시리스트) + 가족 우체통 |

## 포켓몬 마을 (아이별 개인 보관함)

- **스티커**: 퀘스트를 하나 끝낼 때마다 1장, 또는 **부모님 스티커 주기(+1/+3/+5장)** 로 쌓입니다.
- **성장 순서**: 알 → 1단계 → 2단계 → 최종 진화. 단계마다 스티커가 필요합니다(알 3장 · 1차 진화 4장 · 최종 진화 6장, 뮤는 알 8장).
- **보관함에 넣기**: 최종 진화를 마치면 **[📦 보관함에 넣고 새 알 받기]** 버튼이 나옵니다. 누르면 그 포켓몬이 아이의 마을에 들어가고 새 알을 받습니다.
- **포켓몬 마을**: 오른쪽 넓은 초원에 지금까지 다 키운 포켓몬이 한국어 이름표와 함께 모입니다(한 화면 14마리, 그 이상은 [+N마리] 표시). 포켓몬을 누르면 도감 상세가, **[📖 보관함 목록]** 을 누르면 전체 목록과 정렬(최근·오래된·도감번호·이름)이 열립니다.
- **최근 스티커**: 언제 어떤 퀘스트·칭찬으로 스티커를 받았는지 기록이 쌓입니다.
- 아이마다 알·스티커·보관함이 **따로** 저장됩니다.

### 포켓몬 도감 (12계열 · 31종)

파이리 · 피카츄 · 꼬부기 · 이상해씨 · 이브이 · 토게피 · 리오르 · 냐오불 · 뜨아거 · 꾸왁스 · 먹고자 · 뮤 계열의 진화 라인이 들어 있고, 알에서는 이 중 하나가 무작위로 나옵니다(첫 알은 각 아이의 스타터 — 이든 파이리, 이솔 피카츄, 이온 꼬부기).

## 쓰는 법

- 집 태블릿에서 열어 두고 대시보드의 **🖥️ 대기화면** 버튼을 누르면 전체화면 벽걸이 모드가 됩니다 (나가기는 ESC 또는 같은 버튼).
- 퀘스트·XP·스티커·포켓몬·위시리스트·메모는 **이 기기 브라우저(localStorage)** 에 즉시 저장됩니다.
- **여러 기기(태블릿 + 휴대폰)가 같은 내용을 함께 보려면** ⚙️ 실시간 동기화 설정에서 Firebase Realtime Database 주소를 한 번 넣어 주세요. 5초마다 서로 맞춰집니다. 포켓몬 보관함과 스티커 기록도 함께 동기화됩니다. (아래 준비 방법 참고)

### Firebase 동기화 준비 (처음 한 번)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트를 만들고 **Realtime Database**를 만듭니다.
2. Rules 를 아래처럼 두면 이 대시보드가 읽고 쓸 수 있습니다.

   ```json
   {
     "rules": {
       "family": { ".read": true, ".write": true }
     }
   }
   ```

3. Realtime Database 데이터 탭 위쪽의 주소(`https://…firebaseio.com`)를 대시보드의 **⚙️ 실시간 동기화 설정**에 붙여넣고 **연결하고 저장**을 누릅니다.

동기화에는 아이들 이름, 퀘스트, 스티커, 포켓몬 보관함, 위시리스트, 메모만 담깁니다. 전화번호·주소·이메일 같은 개인정보는 넣지 마세요.

## 내용 바꾸기

날씨, 오늘 일정, 캘린더 일정, D-Day, 기본 퀘스트는 모두 **`data.json`** 한 파일에서 고칩니다.
포켓몬 도감(이름·타입·진화 라인·필요 스티커 수)도 `data.json` 의 `pokemon` 항목에 있습니다.

```json
{
  "weather": { "summary": "대체로 흐림", "tempMin": 10, "tempMax": 16 },
  "kids": [ { "id": "idun", "quests": [ { "text": "아침밥 다 먹기", "xp": 20 } ] } ],
  "events": [ { "date": "2026-11-17", "title": "거미놀이 오감놀이", "type": "school" } ],
  "pokemon": { "costs": { "hatch": 3, "evolve1": 4, "evolve2": 6 } }
}
```

파일을 고쳐 `main` 브랜치에 올리면 1분 안에 사이트에 반영됩니다.

## 파일 구성

```
index.html        화면 뼈대 (상단 탭 + 5개 화면)
styles.css        디자인 (따뜻한 크림 배경 + 포켓몬 타입 색)
app.js            포켓몬 성장·보관함·스티커, 퀘스트·XP, 캘린더, 위시리스트, 우체통, 동기화
data.json         날씨·일정·퀘스트·포켓몬 도감 등 내용 (여기만 고치면 됨)
pokemon-sheet.png 포켓몬 공식 일러스트 31종 (PokéAPI 스프라이트를 8×4 격자 한 장으로 묶음)
pokemon-4.png, pokemon-25.png, pokemon-7.png   아이 카드용 대표 일러스트
pokemon/artwork/  낱장 원본 일러스트 (사이트에는 올리지 않는 보관용)
```

포켓몬 이미지는 [PokéAPI sprites](https://github.com/PokeAPI/sprites)에서 가져왔습니다. 포켓몬과 관련 이름은 닌텐도·포켓몬컴퍼니의 상표이며, 이 저장소는 가족이 집에서 쓰는 비상업용 화면입니다.
