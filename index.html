보관함에는 부화·진화를 끝낸 포켓몬만 들어가요. 마을에 모인 친구들은 계속 남아 있어요.

⚙️ 실시간 동기화 설정

태블릿과 휴대폰이 같은 퀘스트·XP·스티커·포켓몬 보관함·위시리스트·메모를 함께 보게 하려면 Firebase Realtime Database 주소를 넣어주세요. 주소를 비워두면 이 기기에만 저장돼요.

Firebase 콘솔 → Realtime Database → 데이터 탭 위쪽의 주소를 그대로 붙여넣으면 됩니다. 주소 끝의 /는 붙여도 괜찮아요.

아직 연결하지 않았어요.
처음 한 번만 준비하면 되는 것
  1. Firebase 콘솔에서 프로젝트를 만들고 Realtime Database를 켭니다.
  2. 규칙(Rules)을 아래처럼 두면 이 대시보드가 읽고 쓸 수 있어요. 개인정보가 없는 화면이라 값은 이름·퀘스트·포켓몬 정도만 담깁니다. 
    {
  "rules": {
    "family": { ".read": true, ".write": true }
  }
}
  3. 위 주소를 여기에 붙여넣고 연결하고 저장을 누르면, 이후 모든 기기가 5초마다 서로 맞춰집니다.
